# Safa Oujri | Portfolio

Personal portfolio website built with **Spring Boot** and **Thymeleaf**. It presents my background, skills, projects, experience and certifications, with a contact form.

## Features

- Responsive design (desktop, tablet and mobile)
- Loading animation and animated hero section with a typing effect
- Skills grid, experience timeline and certifications with category filters
- Projects section and contact form with client-side validation
- Reusable Thymeleaf fragments for each section (header, hero, about, experience, certification, contact, footer)
- Smooth scrolling, active menu link and back-to-top button

## Tech stack

- Java 21
- Spring Boot, Spring MVC
- Thymeleaf
- HTML5, CSS3, JavaScript
- Maven

## Project structure

```
src/main/resources/
├── templates/
│   ├── home.html
│   └── fragment/        # header, hero, about, experience, certification, contact, footer
└── static/
    ├── css/style.css
    ├── js/script.js
    └── Images/
```

## Run locally

Prerequisites: Java 21 and Maven.

```bash
git clone https://github.com/safaoujri/Oujri_Safa_Portfolio.git
cd Oujri_Safa_Portfolio
mvn spring-boot:run
```

Then open http://localhost:8080
